Public Analytics API

Request

GET /api/public/analytics

No authentication. Session cookies are ignored. The endpoint accepts GET and CORS preflight only, and it does not write data.

Responses use application/json and America/Chicago for every date. Amounts are USD numbers. Hours are rounded to one decimal place.

The data endpoint allows {{ rate_limit }} requests per {{ rate_window }} seconds for each connecting address. Docs and the OpenAPI document are not counted. Successful responses include X-RateLimit-Limit and X-RateLimit-Remaining. A limited response is HTTP 429 with Retry-After.

Cross-origin GET is allowed (Access-Control-Allow-Origin: *) so a browser-based bot can call it. Do not send credentials.

What filters change

With no parameters, the payload matches the analytics overview: time totals are all-time, and the project hour ranking uses the rolling last 30 days. Summary cards, client counts, and membership figures always describe the organization right now.

{% for label, effect in effects %} {% endfor %}
Part of the responseHow filters apply
{{ label }}{{ effect }}

On an unfiltered request, time also includes total_hours_all_time, total_hours_last_30_days, hours_this_week, hours_last_week, and total_logs. Those keys are left out as soon as a date, project status, or bill type filter is present, so a filtered time.hours is not mistaken for the overview total.

filters.window describes the requested date window. start and end are inclusive calendar dates. start_at and end_at are exact timestamps; end_at is exclusive. A rolling last-30-days window has no end_at.

Each point in time.series is rounded on its own, so the sum of points can differ from time.hours by a tenth. series.date is the bucket start: the day, the Monday, or the first of the month.

Ask for the projection on its own with ?section=projection. period=fiscal_year returns all 12 months. A shorter period returns the months that overlap it. Profited and projected bill rows include the bill title and profit amount, not the client. Salaries are one combined monthly cost.

Filtered responses keep the same panel objects. time.hours and time.logs then describe the requested window, the overview-only time keys are omitted, and time.series is filled unless you pass series=0.

Errors

Errors are JSON. parameter names the query parameter to fix. allowed lists the accepted values when that is useful.

{
  "error": "Unknown period.",
  "parameter": "period",
  "allowed": ["today", "this_week", "last_week", "last_30_days", "this_month", "last_month", "fiscal_year", "all_time"]
}
StatusWhen
200The query is valid. Empty rankings are empty arrays, not errors.
400Unknown or invalid parameter, a one-sided date range, or a series that is too long.
405Any method other than GET or OPTIONS.
429The address exceeded {{ rate_limit }} data requests in {{ rate_window }} seconds.

The machine-readable contract is the OpenAPI document.
